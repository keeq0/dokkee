# dokkee

Монорепозиторий: лендинг + основное приложение + backend сервис анализа документов.

Подробная документация по запуску, переменным окружения, миграциям, seed и тестам появится в PR-7. Текущий статус: каркас монорепы (PR-1).

## Состав

- `frontend/` - Vue 3 SPA (лендинг + приложение + админка)
- `backend/` - Go API
- `nginx/` - reverse-proxy для локального запуска
- `docs/` - документация и аналитика

## Быстрый запуск

```bash
make up      # поднять весь стек через docker-compose
make test    # прогнать тесты обеих частей
make down    # остановить
```
